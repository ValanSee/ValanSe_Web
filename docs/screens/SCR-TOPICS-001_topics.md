## 🎯 화면 목적

"밸런스게임 주제", "연애 밸런스게임" 같은 검색어로 들어온 사용자에게 인기 질문과 카테고리별 질문을 한 페이지에 모아 보여주고, 바로 투표(상세)로 이어지게 한다. 상세 페이지로 가는 내부 링크를 모아 크롤링 경로 역할도 한다.

## 🚪 진입 경로

- 홈 `이런 주제는 어때요?` 섹션의 `더보기`
- PC 푸터 `밸런스게임 주제 추천`
- 검색 결과 (sitemap 등록, canonical `/topics`)

## 🖥️ 렌더링 (SEO)

- 전체 인기순 10개 + 카테고리 6개 각 인기순 5개를 서버에서 비로그인으로 조회해 SSR (`GET /votes`, 60초 캐시)
- title `밸런스게임 주제 추천 모음 - 연애·음식·친구 밸런스 질문`, canonical `/topics`
- JSON-LD: BreadcrumbList (홈 › 밸런스게임 주제 추천), ItemList (인기 10개)

## 📐 레이아웃 구성

1. **헤더** (모바일 전용, 뒤로가기 · `주제 추천`)

5. **밸런스게임 이렇게 즐겨요** — 안내 3문항 + `밸런스게임 만들기` 버튼
6. **하단 네비게이션 바** (모바일)

## 🧩 섹션별 상세 명세

### 3~4. 주제 목록

**표시 데이터**: 제목 · `A vs B` · 참여자 수 (인기 목록은 순위 번호 포함)

**사용자 액션**

- 항목 클릭 → `/poll/{id}`
- 카드 `더보기` → 인기 목록 `/balanse?sort=popular`, 카테고리 카드는 `/balanse?category={카테고리}&sort=popular`

**상태별 처리**

- 카테고리 조회 실패 · 결과 없음 → 해당 카드만 미노출
- 인기 목록 실패 → 인기 카드 미노출 (나머지는 그대로)
- 내가 신고한 투표는 숨김 (아래 예외 상황 참고)

### 5. 안내

- 정적 문구 3개 (밸런스게임이란? · 어디서 하면 좋아요? · 직접 만들 수 있나요?)
- `밸런스게임 만들기` → `/create` (로그인 필요 시 기존 가드 흐름)

## ⚠️ 예외 상황

| 상황 | 처리 |
|---|---|
| API 전체 실패 | 소개 · 안내 섹션만 노출 |
| 내가 신고한 투표 | 목록(홈 · 밸런스)과 동일하게 숨김, 순위는 남은 항목으로 다시 매김. 카드의 항목이 모두 숨겨지면 카드도 미노출 (로컬 저장 기준, 서버 HTML 에는 전체 목록) |

| Method | Endpoint | 용도 |
|---|---|---|
