## 🎯 화면 목적

탈퇴 시 삭제되는 데이터 안내를 읽고 동의 후 계정을 영구 삭제한다.

## 🚪 진입 경로

- 내 정보(`/my`) → 계정 관리 섹션 → "계정 삭제"

## 📐 레이아웃 구성

1. **헤더** (뒤로 가기)
2. **삭제 안내 본문** (삭제될 데이터, 복구 불가 명시)
3. **동의 체크박스**
4. **삭제 버튼** (체크박스 동의 시 활성화)

## 🧩 섹션별 상세 명세

### 1. 안내 본문

**목적**: 사용자에게 비가역적 영향을 명확히 고지

**표시 데이터**: 정적 텍스트 (TODO: 정책 카피 확정)

### 2. 동의 체크박스 + 삭제 버튼

**사용자 액션**

- 체크박스 토글
- 삭제 버튼 클릭 → 확인 팝업("정말로 계정을 삭제할까요?") → [삭제] → 탈퇴 API(`signout` → `POST /auth/withdraw`) 호출

**상태별 처리**

- **체크 안 됨**: 삭제 버튼 비활성화
- **처리 중**: 버튼 비활성화 + 인디케이터
- **성공**: "계정이 삭제되었어요" 팝업 → [확인] 시 `/entry` 이동 후 세션 정리(`clearSession`: Redux · 토큰)
  - 세션을 먼저 지우면 (auth) `AuthGuard` 가 화면을 로딩으로 바꿔 팝업이 사라지고 멈추므로, 반드시 팝업 확인 뒤에 정리한다
- **실패**: 에러 팝업("계정 삭제 중 오류가 발생했어요") → 로그인 상태 유지, 다시 시도 가능

## 🔄 사용자 시나리오

**시나리오 1: 정상 탈퇴**

1. 안내 읽기
2. 동의 체크
3. 삭제 버튼 클릭
4. 계정 삭제 → 완료 팝업 확인 → `/entry` 이동 · 로그아웃
