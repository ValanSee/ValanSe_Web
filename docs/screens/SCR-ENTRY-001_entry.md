## 🧩 섹션별 상세 명세

### 1. KakaoLoginButton

**사용자 액션**

- 클릭 → 카카오 OAuth 인가 페이지 이동
- 인가 후 `/oauth/kakao/redirect`로 콜백

### 2. 로그인 없이 시작하기

**사용자 액션**

- 클릭 → `/main`(홈)으로 이동
- 보호 페이지(`/my` 등)에서 튕겨온 사용자의 유일한 탈출로.
  `router.back()` 으로 되돌아가면 가드가 다시 `/entry`로 보내 루프가 발생하므로
  공개 홈으로 명시적으로 이동시킨다.

## 🔄 사용자 시나리오

**시나리오 1: 최초 로그인**

1. `/entry` 진입
2. 카카오 로그인 버튼 클릭
3. 카카오 인가 → 콜백 → 신규면 `/onboarding`, 기존이면 `/main`

**시나리오 2: 로그인 필요 기능에서 튕겨온 뒤 로그인하지 않음**

1. 마이/투표 등에서 미인증 → `/entry?redirect=<원래경로>` 진입
2. '로그인 없이 시작하기' 클릭 → `/main`(홈)으로 복귀 (막다른 길 없음)
