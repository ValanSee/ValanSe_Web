## 🎯 화면 목적

내가 차단한 사용자를 확인하고 차단을 해제한다. 사용자 생성 콘텐츠 앱의 차단 기능 요구(App Store 가이드라인 1.2)에 대응.

## 🚪 진입 경로

- 마이(`/my`) > 계정 관리 > "차단한 사용자"
- 차단 완료 팝업 안내 문구("마이 > 차단한 사용자에서 해제할 수 있어요")

## 📐 레이아웃 구성

1. **헤더** — 뒤로 / "차단한 사용자"
2. **안내 문구** — "차단한 사용자의 밸런스 게임과 댓글은 보이지 않아요"
3. **목록** — 닉네임 + "차단 해제" 버튼 (최근 차단 순)
4. **빈 상태** — "차단한 사용자가 없어요"

## 🧩 섹션별 상세 명세

### 3. 목록

**표시 데이터**

| 항목 | 출처 | 비고 |
|---|---|---|
| 닉네임 | `GET /member/blocks` → `blocks[].nickname` | 프로필이 없으면 "알 수 없는 사용자" |

**사용자 액션**: "차단 해제" → `DELETE /member/blocks/{memberId}` → 목록에서 즉시 제거. 이후 그 사용자의 글이 다시 목록에 보임

## 🔄 사용자 시나리오

1. 투표 상세 · 댓글의 ⋮ 메뉴에서 "이 사용자 차단" → 확인 → 차단 완료 팝업
2. 마이 > 차단한 사용자 진입 → 목록 확인
3. "차단 해제" → 목록에서 사라짐

## ✅ 수용 기준

- Given 차단한 사용자가 없을 때 When 진입하면 Then 빈 상태 문구를 보여준다
- Given 차단 목록이 있을 때 When "차단 해제"를 누르면 Then 서버 해제 후 목록에서 제거한다

## ⚠️ 예외 상황

| 상황 | 처리 |
|---|---|
| 목록 조회 실패 | 에러 팝업 + 빈 목록 |

| 미로그인 | (auth) AuthGuard 가 로그인 화면으로 이동 |
